# Exact Contention Implementation Snapshots

`collection/` preserves the code at commit
`9d0e8dcb9d6b87f84b047e83553a6a62f78e7be6`, the commit frozen in the r2
campaign manifests and used to collect the measurements.

`publication/` preserves the final analysis and completion-audit scripts from
commit `70c27e2ff6e43c5ae37bd8d45a7a0ae604303fcf`.

The scripts retain their original repository-relative paths. Copy a snapshot's
`scripts/` and `src/` to the root of a clean checkout before running it; do not
write new measurements into this frozen result directory.
